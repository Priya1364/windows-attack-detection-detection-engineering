# Windows Attack Detection and Detection Engineering

## Project Overview
A practical Windows endpoint security monitoring project using PowerShell, Windows Security Logs and Sysmon.

## Technologies
- Windows 10
- PowerShell
- Sysmon
- Windows Event Viewer
- CSV

## Project Modules
1. Windows Security Log Analysis
2. Failed Login Detection
3. Suspicious Process Detection
4. PowerShell Activity Detection
5. Detection Engineering
6. Automated SOC Investigation
7. Final Reporting

## Project Features
- Windows event collection
- Failed login monitoring
- Process execution monitoring
- PowerShell script monitoring
- Custom detection rules
- Automated CSV alert generation

## Disclaimer
This project is intended for educational and defensive cybersecurity monitoring in a controlled Windows environment.
